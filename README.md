# @saulzayn/rn-keyboard-form

Keyboard-aware forms for React Native: fields stay above the keyboard, a footer rides on it, and sheets scroll the focused field into view.

## Installation


```sh
npm install @saulzayn/rn-keyboard-form
```


## Usage


```js
import { multiply } from '@saulzayn/rn-keyboard-form';

// ...

const result = multiply(3, 7);
```
